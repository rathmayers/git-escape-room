# Campus Café: the back office

It is 23:47. The café is closed, the door has locked behind you,
and the only thing still running is this repository.

The developer who built the café website hid the four letters of the
exit code in the **Git history**. You only need Git commands.

| Lock | Clue |
|------|------|
| 1 | Ada worked the night shift. Her commit message holds **letter 1**. |
| 2 | Someone deleted the file `vault.txt`. It contained **letter 2**. |
| 3 | There is a **basement** in this repository. A note down there holds **letter 3**. |
| 4 | On opening day the owner put a **tag** on the history. Its message holds **letter 4**. |
| Bonus | The latte got more expensive. **Who** changed the price, and **from what to what**? |

Rules: do not edit files to "find" letters, and write down every command
that helped you. The four letters form a word. Turn it into an HTML tag
and bring it to the front.
